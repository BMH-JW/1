# 数据Demo场景

打开 `Assets/GameData/Demo/Scenes/GameDataDemo.unity`，点击 **Play**。也可以从菜单 **Tools → JU → Game Data → 打开Demo场景** 进入。

五个板块：

1. **第X天**：显示天数、纯净、秩序、信任、黑天鹅状态和队列；下拉列表可切换申请者与收容人员。
2. **通关文书**：申报身份、申请目的地、申报身体状况和入境理由。
3. **人物档案**：真实身份、动机、二维标签、四属性定性和真实身体状况。
4. **调试数值**：四项真实数值、欺骗偏差和类型、当前状态以及预计放行影响。
5. **审批操作**：放行乌托邦、放行反乌托邦、拒签入所、闭馆结算四个按钮，以及审批/日终反馈。

审批后自动选择下一名待审批人员。被拒签的人保留在下拉列表的收容部分，可重新选择再审批。变异人员不能放行，已收容人员不能重复拒签。文书、档案与数值正文支持鼠标滚轮滚动。

闭馆统一结算，并自动生成次日申请者；尚未处理的申请者按现有数据规则离开。游戏结束后，前三个按钮停用，第四个按钮改为 **重新开局**。

在 Hierarchy 选择 **GameDataDemoCanvas**，Inspector 的 **Game Data Demo Controller** 中可指定配置资产与随机种子。修改后重新进入 Play 才生效。默认配置和种子为原数据模块配置、42；没有调整数值平衡。

UI 是保存在场景里的标准 UGUI 对象，可以在 Hierarchy 编辑五个板块及文本/按钮位置。Canvas 使用1600×1000参考分辨率等比缩放，建议 Game 窗口使用16:10或16:9，窄屏不是本Demo的布局目标。

中文默认使用 Windows 系统微软雅黑/黑体动态字体。跨平台时，可将有授权、支持中文的 Unity Font 资产拖到 **Font Override**。运行前的编辑器场景预览使用内置字体；运行时会替换为中文字体。

本场景独立运行，不连接原有 RoomScene、时钟或NPC点击脚本，不修改构建场景列表，也不保存进度。停止 Play 后重新开始新局。

测试入口：**Window → General → Test Runner**。EditMode 的 `JU.GameData.Demo.Tests` 检查场景引用；PlayMode 的 `JU.GameData.Demo.PlayModeTests` 验证四按钮、鼠标射线点击、人员切换、收容、结算、失败与重新开局。

本次使用 Unity 2022.3.62f3c1 在隔离项目验证：21项 EditMode 测试（包含20项原数据回归）及1项完整 PlayMode 交互测试全部通过；1600×1000场景预览已检查中文、正文换行和五板块布局。原项目未被用于批处理测试。
